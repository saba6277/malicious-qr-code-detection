\# Notebook Guide



The repository is organized as a sequential seven-notebook workflow.



\## Notebook Sequence



| Notebook | Description |

|----------|-------------|

| 01\_dataset\_preparation.ipynb | Dataset preparation and preprocessing |

| 02\_feature\_extraction\_and\_fusion.ipynb | Handcrafted feature extraction and feature fusion |

| 03\_tabnet.ipynb | Proposed TabNet classifier |

| 04\_mobilenetv2.ipynb | Proposed MobileNetV2 classifier |

| 05\_lightgbm\_baseline.ipynb | LightGBM baseline implementation |

| 06\_lightweight\_cnn\_baseline.ipynb | Lightweight CNN baseline implementation |

| 07\_dataset\_validation\_and\_reliability.ipynb | Dataset validation, artifact analysis, sanity checks, and robustness evaluation |



The notebooks should be executed sequentially because later notebooks depend on files generated during earlier stages.
